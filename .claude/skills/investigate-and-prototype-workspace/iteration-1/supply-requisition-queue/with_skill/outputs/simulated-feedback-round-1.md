## What this surfaces
- **"Flagged isn't fixed"** — the same recurring gap already identified
  elsewhere in this repo's investigations (Director brief / prototype
  round for Dispatch's Second Chance work). It shows up again here, in a
  completely different product area, from a different simulated voice.
  Worth treating as a standing requirement for Supply's 4.3 work too, not
  just a one-off note: a visual re-sort is not the same as a faster real
  decision.
- **Two sharp, answerable questions for whoever scopes 4.3:** (1) who or
  what actually assigns the urgency tier, and is it gameable if it's
  self-reported; (2) does tiering change actual approval *time*, or only
  display order. Neither is answerable from this repo — pass both along
  with the hand-off rather than treating the mockup itself as a proposal.
- Does not move the 25/100 confidence number — this is illustrative
  feedback on a made-up mockup, not new real-world evidence, per the
  skill's own rule.
